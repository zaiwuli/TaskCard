# TaskCard

极简 **随机任务抽取 + 小红书/朋友圈配图生成 + NAS 定时批量出图** 工具。

仓库地址：https://github.com/zaiwuli/TaskCard

## 核心特性
- **极简界面**：打开页面即用，点击一次抽取一个任务，一键生成配图。
- **NAS 定时批量生成**：内置轻量调度器，支持每天指定时间（如凌晨 `00:00`）自动抽取 N 个任务并渲染成 PNG 图片（例如每天自动出 20 张）。
- **严格防重复**：服务端将任务池与剩余队列持久化在 `/data/state.json`，**所有任务全部抽完前绝不重复**，NAS 重启不丢失进度。
- **目录自动归档**：后缀留空时直接按日期建目录（如 `output/2026-11-26/`），填写后缀时按 `output/2026-11-26_后缀/` 归档。
- **足够轻、省内存**：纯 Go 单二进制，不依赖无头浏览器，常驻内存仅约 **15~30MB**。

## 快速部署（NAS / Docker Compose）

仓库已配置 GitHub Actions 自动构建 `linux/amd64` + `linux/arm64` 多架构镜像，NAS 直接拉取运行即可（无需在 NAS 上编译）：

```yaml
services:
  taskcard:
    image: ghcr.io/zaiwuli/taskcard:latest
    container_name: taskcard
    ports:
      - "8080:8080"
    volumes:
      - ./output:/output
      - ./data:/data
    restart: unless-stopped
```

启动命令：
```bash
docker compose up -d
```

按需修改 `docker-compose.yml` 中的宿主机挂载目录：
- `./output:/output`：生成图片的存放目录
- `./data:/data`：任务列表与抽取进度持久化目录
- `./fonts:/fonts`：自定义字体目录（可选，放入 `.ttf`/`.otf`/`.ttc` 文件重启即优先使用）

启动后浏览器访问：`http://你的NAS地址:8080`

## 任务导入模板

支持在网页右下角 **「编辑任务」** 中直接粘贴，或点击 **「导入 TXT」** 导入纯文本文件（参考 [tasks.example.txt](./tasks.example.txt)）。

### 格式规范
- **每行 1 条任务**（UTF-8 纯文本），系统会自动忽略空行并去重。
- **不要带序号或符号**（如 `1.`、`- `、`* `），否则会一起印到图片上。
- 建议每条控制在 **8~35 个汉字**，在小红书 3:4 / 朋友圈 1:1 卡片上排版最美观。

示例：
```text
今天早起喝一杯温水并记录感受
整理手机相册，删掉 20 张不需要的照片
读完一本书的任意一个章节并写 1 句话总结
晚饭后出门散步 20 分钟不看手机
```

### 让 AI 批量生成任务的提示词模板
可直接复制发给任意 AI，生成后保存为 `.txt` 导入：

```text
请帮我生成 200 条关于【填写主题，例如：每日自律打卡 / 小红书日常灵感】的任务。
严格遵守以下输出格式要求：
1. 纯文本输出，每行 1 条任务；
2. 不要任何序号（如 1. 2.）、不要项目符号（如 - *）、不要分类标题、不要空行、不要开头结尾说明；
3. 每条任务内容不重复，长度控制在 10~30 个汉字之间，适合直接印在小红书配图上。
```

## API 手动触发（可选）

除了内置定时任务，也可以通过 NAS 自带计划任务或脚本调用接口触发批量生成：

```bash
curl -X POST http://127.0.0.1:8080/api/batch \
  -H "Content-Type: application/json" \
  -d '{"count":20,"suffix":""}'
```
