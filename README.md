# TaskCard

极简 **多任务库随机抽取 + 小红书/朋友圈配图生成 + NAS 定时按库批量出图** 工具。

仓库地址：https://github.com/zaiwuli/TaskCard

## 核心特性
- **多任务库管理**：可自由新建、重命名、删除多个任务库（如 `1号库`、`2号库`、`3号库`），每个库独立维护任务列表、独立防重复队列，也可单独开关是否参与定时生成及设置单库每次生成张数。
- **按日期 + 任务库自动分目录归档**：每天定时自动按如下结构生成图片：
  ```text
  output/
  └── 20261126/
      ├── 1号库/
      ├── 2号库/
      └── 3号库/
  ```
  （若填写了目录后缀，则生成 `20261126_后缀/1号库/`）
- **支持多行任务**：单个任务内需要换行时，用单独一行 `---` 隔开不同任务，出图时自动保留换行排版。
- **严格防重复**：服务端将每个库的剩余队列持久化到 `/data/state.json`，**该库所有任务全部抽完前绝不重复**，NAS 重启不丢失进度。
- **足够轻、省内存**：纯 Go 单二进制，不依赖无头浏览器，待机内存仅约 **10~20MB**，批量出图后主动归还内存。

## 快速部署（NAS / Docker Compose）

仓库已配置 GitHub Actions 自动构建 `linux/amd64` + `linux/arm64` 双架构镜像：

```yaml
services:
  taskcard:
    image: ghcr.io/zaiwuli/taskcard:latest
    container_name: taskcard
    ports:
      - "8080:8080"
    volumes:
      - ./output:/output
      - ./data:/data
    restart: unless-stopped
```

启动命令：
```bash
docker compose up -d
```

启动后浏览器访问：`http://你的NAS地址:8080`，所有定时任务、任务库和配图样式均可直接在网页内配置。

## 任务导入模板（支持多行）

在网页右下角 **「任务库」** 中可直接编辑，或点击 **「导入 TXT」** 导入纯文本文件（参考 [tasks.example.txt](./tasks.example.txt)）。

### 格式规范
- **多行任务**：正常换行书写，不同任务之间用**单独一行 `---`** 隔开。
- **单行任务**：如果全文不含 `---`，则自动兼容按每行 1 条拆分。
- 不要加 `1.`、`2.` 等序号，否则会一起印到图片上。

示例：
```text
今日自律打卡
早起喝一杯温水
记录当下感受
---
整理手机相册
删掉 20 张不需要的照片
---
晚饭后出门散步 20 分钟
全程不看手机
```

### 让 AI 批量生成多行任务的提示词模板
```text
请帮我生成 200 条关于【填写主题，例如：每日自律打卡 / 小红书日常灵感】的任务卡片文案。
严格遵守以下输出格式要求：
1. 纯文本输出，每条任务可以包含 1~3 行文字（适合排版展示）；
2. 不同任务之间必须用单独一行 --- 隔开；
3. 不要任何序号（如 1. 2.）、不要项目符号、不要开头结尾说明；
4. 每条任务内容不重复，总字数控制在 10~40 个汉字之间，适合直接印在小红书配图上。
```

```bash
# 对所有已启用的任务库执行一次批量生成
curl -X POST http://127.0.0.1:8080/api/batch \
  -H "Content-Type: application/json" \
  -d '{}'
```
